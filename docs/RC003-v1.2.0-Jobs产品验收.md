# Jobs 产品验收（独立第二轮）—— RC003 v1.2.0

**方法**：从首次打开软件、完成单次配置、反馈、错误、移动窄屏五条真实用户路径重新检验。日期 2026-10-15。

**结论：PASS WITH ISSUES。**

## 首次使用可发现性
- 导航分为：首页、① 系统级、② 应用级、③ 独立语音、维护。首屏解释电源音量优先 Linux、普通按键因应用变化。
- 首次使用说明：先看连接状态→选择应用→编辑并保存。8 页分组明显。
- 系统页面显示电源、睡眠、音量+/−、静音、亮度+/−共 7 项，但标注“策略锁定不等于硬件测通”。
- 浏览器/ChatGPT/WPS 的普通按键由下拉框选；系统键不会出现在应用编辑器中。微信语音独立页面。

## 先发现后修复
- 初版截图中左导航有重复高亮感；修正初始化时只有一个 active 页面。
- 初版手机窄屏侧栏占用过多可视空间；改为保留五组层级的页面选择器。
- 首页原先导航/卡片重复，删除一组价值较低的快捷卡片。
- 没有修改时隐藏主保存按钮；操作中显示处理中，完成提示结果。
- 缺少后端时先前会误报绿色设备正常；改成明确的待安装提示和红色未就绪状态。

## 产品测试证据
- 真正候选源码在隔离 Electron Runtime 下启动，核对 8 页、11 条规则及 7 个系统锁定键。
- 浏览器新增映射弹窗：不包含电源、睡眠和系统音量；取消不写入配置。
- 默认规则来自后端 IPC，未复制第二份 JavaScript 模板。
- 390px 设备模拟：没有横向滚动，分组导航可用，未修改时不显示保存按钮；桌面和窄屏截图人工复核。
- 不存在后端时仍能看见系统层和故障说明，不显示虚假的绿色状态。

## 产品遗留项
- 新用户需要先部署 Linux 后端；未来仍值得设计一键部署引导。
- 尚未在真实 RC003 上复测关机/音量/全屏微信/WPS 全链路，不能将截图验收等同硬件验收。
- 窄屏仅指 Electron 响应式布局，不是 Android/iOS 原生应用。

**判断**：新人能区分系统、应用、语音三层并找到主要操作入口。上述非阻塞问题必须公开，不得声称全平台无障碍使用。
