## 设计边界
- key_layers.py 是系统级保护键单一来源；remote_rules.py 只校验应用层，系统键无法配置；video_only_hid.py 是唯一前台 HID 抓取/路由服务；gatt_key_bridge.py 只解码已知 BLE HID；wechat_dictation.py 是独立语音通道。Electron 仅有白名单 IPC 配置与 systemd 控制权，不接管 HID。
- 优先级固定为系统键直通 Linux → 语音通过独立服务 → 其他键按前台应用匹配 → 无匹配时原样透传。
- HID 电源/睡眠只从真实标准报告解码，不通过前端运行关机命令；有五秒重复触发防护。
- Electron 保持 sandbox、contextIsolation，禁止 nodeIntegration；规则仅允许严格枚举的快捷键，不接收用户命令。
- 删除 JavaScript 里重复的默认 11 条规则，Electron 经后端读取 Python 唯一来源。缺失后端/指定路径不存在时 fail closed，不假报“已连接”。
- 无效规则校验失败时不覆盖；热重载只采用最后有效规则；保存前生成备份；保持原蓝牙鼠标设备独立。
- 原 legacy HID 方案作为非默认可选实现保留，不能与唯一活动抓取服务同时运行。
