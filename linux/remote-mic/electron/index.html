APP PROFILE / 02

ChatGPT

对话控制与浏览器快捷键分开管理，防止误提交。

网页专属操作
发送消息需由网页脚本确认；网页中普通 Enter/OK 不允许自定义映射，以保护手动输入。

对话按键

APP PROFILE / 03

WPS 演示

会议、教学和演示场景专用配置。

前台窗口生效
默认 OK → F5，返回 → Esc。退出放映后再次按 OK 会尝试恢复 WPS 窗口焦点；不抢占浏览器。

演示按键

仅在识别到 WPS 演示时生效。

VOICE PROFILE / 04

微信语音输入

按住说话，松开结束；先检查文字，再由 OK 决定是否发送。

语音专用

语音偏好

设置只保存在本机，不会上传聊天文字或录音。

微信语音键来自 BLE 音频事件，不允许绑定到浏览器快捷键。系统必须能够确定当前窗口为微信。
