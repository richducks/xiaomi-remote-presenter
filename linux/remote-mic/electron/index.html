LAYER 01 · SYSTEM

电源与系统按键

这组键优先交给 Linux 操作系统；浏览器、微信、WPS、ChatGPT 均无权覆盖。

系统级 · 禁止改写
作用优先级：系统键直通 → 语音由独立 BLE 服务处理 → 其他键按前台应用匹配 → 无匹配时保留原始按键。
电源键触发的是 Linux 既有电源策略，不是软件直接执行关机命令；是否能收到电源事件，取决于遥控器型号与 HID 固件。

系统保留按键

“系统保留”表示软件不会改写此键，不代表硬件已经实测通过。

不可在应用层选择

为什么不能编辑？

系统键的优先级高于所有应用。修改为浏览器快捷键会导致音量在微信、WPS、视频和桌面之间行为不一致，电源键误触还可能造成未保存数据丢失。
